The Private Editorial Atelier for macOS.

Elocutio combines a six-pillar macOS writing studio with a non-activating system-wide elo companion. On-device Harper rules catch mechanical slips in under 10 ms; 6 AI provider presets (including Apple Foundation Models on-device) power deep rewrites; and a local SQLite vault keeps your Voice DNA and encrypted keys on your Mac.

Architecture & Privacy

Engineered with a strict two-process trust boundary.

The highlighter subprocess reads Accessibility fields and renders non-activating underlines; the Tauri main process owns SQLite, Keychain secrets, and network egress.

01 · Process Isolation

Two-Process macOS Architecture

Accessibility text capture and pasteboard + ⌘V write-ladder injection run in an isolated subprocess with zero network or Keychain access.

02 · Local SQLite Vault

AES-256-CBC + Keychain Storage

elocutio.sqlite3 stores your custom lexicon, rule overrides, Voice DNA, token ledger, and AES-256-CBC encrypted API credentials with PBKDF2-HMAC-SHA256.

03 · Adaptive macOS Chrome

Template Menu Bar & Floating “elo”

Uses macOS WindowServer template rendering so the menu-bar icon adapts automatically to dark and light wallpapers, paired with a focus-preserving floating elo pill.

Two-Process Architecture & Write Ladder

Elocutio separates secret/network ownership from cross-app Accessibility access so API keys never enter the process that inspects external windows:

Capability Tauri Main Process Highlighter Subprocess
API Keys (Keychain + Encrypted SQLite) Yes Never
Network Egress (OpenRouter / OpenAI / Groq) Yes Never
macOS Accessibility & Non-Activating Overlay Coordinator Direct AX Broker

Local SQLite Vault & Data Privacy

All personalization and telemetry live on your Mac in ~/Library/Application Support/elocutio/elocutio.sqlite3. There is no Elocutio cloud account or middleman server.

SQLite Table / File Contents Protection & Control
encrypted_credentials Provider API keys AES-256-CBC + 10k-iter PBKDF2-HMAC-SHA256 + macOS Keychain
ai_token_usage Model slug, prompt/completion tokens, USD cost, latency Stores zero user prose; clearable anytime
dictionary_words Custom single-word lexicon entries Synced with user_dictionary.txt; searchable & editable
editorial_rules Per-rule Harper lint enable/disable overrides Instant toggle in Lexicon & Rules
voice_profile & edit_events Calibrated Voice DNA traits & accepted/dismissed edit counts Local-only learning; one-click reset
